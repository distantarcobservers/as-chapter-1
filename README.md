# Arcane Systems — Chapter 1 Final Viewer

Static site prepared for GitHub Pages.

## Structure

- `index.html` — site entry point
- `assets/css/style.css` — page styling
- `assets/images/` — extracted Chapter 1 page images and final illustration

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder, then save.

GitHub Pages will serve `index.html` automatically.
